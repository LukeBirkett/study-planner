In modern machine learning, coordination over networks is often cast as a **Decentralized POMDP** where communication protocols and policies are parameterized by Graph Neural Networks (GNNs). **Message Passing Neural Networks (MPNNs)** applied to decentralized execution.

[**DGN (Graph Convolutional Reinforcement Learning)** (_Jiang et al., 2020_)](https://arxiv.org/abs/1810.09202): Models interactions between agents as a dynamic relational graph where agents use multi-agent graph convolutional layers to coordinate actions.

[**TarMAC (Targeted Multi-Agent Communication)** (_Das et al., 2019_)](https://arxiv.org/abs/1810.11187): Uses attention mechanisms to learn _who_ to communicate with, effectively learning a soft adjacency matrix dynamically.

A major contemporary direction is investigating how topology impacts reasoning, deliberation, and collective problem-solving in networks of Large Language Model (LLM) agents.

[**_GPTSwarm: Language Agents as Graphs_** (_Zhuge et al., 2024_)](https://proceedings.mlr.press/v235/zhuge24a.html): Formalizes agent interactions explicitly as computational graphs, optimizing node operations and edge topologies.
